今の変更をコミットしてください。補足: $ARGUMENTS

1. `git status` と `git diff` で変更内容を確認する
2. 今の作業と関係ないファイル（`.vscode/` や練習用のファイルなど）は含めない。迷うものは確認する
3. 変更が複数の目的にまたがっていたら、目的ごとにコミットを分ける
4. コミットメッセージは `git log --oneline -10` の書式に合わせる
   - 1行目: `feat:` / `fix:` / `style:` / `refactor:` / `chore:` / `docs:` などのプレフィックス＋日本語で「何をするか」
   - 必要なら空行のあとに、なぜそうしたかを箇条書きで
5. `main` ブランチにいる場合は、コミットの前に作業用ブランチを切る

プッシュは、私が頼んだときだけ行ってください。
