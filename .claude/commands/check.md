---
description: 型チェック・lint・整形チェック・ビルドをまとめて実行し、結果を報告する
---

コミットやマージの前の確認として、次を順番に実行してください。

1. `npx tsc --noEmit`（型チェック）
2. `npm run lint`（ESLint）
3. `npm run format:check`（Prettier の整形チェック）
4. `npx next build`（本番ビルド）

途中で失敗しても残りは続けて実行し、最後に次の形でまとめて報告してください。

- 各ステップの成否（✅ / ❌）
- 失敗したステップは、エラーが出たファイルと行、原因の要約
- 直し方の提案（直すのは私が頼んだときだけ）

整形チェックだけが失敗している場合は、`npm run format` で直せることも伝えてください。
